# Machine Learning with TensorFlow

A one-week hands-on learning journey focused on understanding the fundamentals of **Machine Learning** and implementing models using **TensorFlow** and **Keras**.

The goal of this repository is to learn by building small models, experimenting with datasets, and understanding the complete ML workflow.

## Learning Goals

* Understand core Machine Learning concepts
* Learn the basics of neural networks
* Work with TensorFlow and Keras
* Prepare and preprocess datasets
* Build, train, and evaluate ML models
* Understand model performance and overfitting
* Experiment with real-world datasets
